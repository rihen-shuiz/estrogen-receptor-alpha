# Limitation: C-alpha only

Every distance in this analysis is a C-alpha RMSD. The core fit, the pairwise matrix (`results/rmsd_entry.npy`) and the H12 metric (`results/h12_metric.csv`) use only C-alpha atoms, so side-chain positions are never measured. A side chain can rearrange while the backbone stays close: a changed rotamer at the ligand pocket, a flipped aromatic or acidic side chain, or a new hydrogen-bond partner can separate an agonist-like site from an antagonist-like site with little C-alpha movement. Entries that differ only in that way would fall into the same cluster, so the clustering, the diversity curves and the representative set could miss a functionally distinct pocket state and report too little diversity. The reverse can also happen: a larger C-alpha RMSD can come from loop or terminal movement that has nothing to do with the bound ligand class. The diversity reported here is therefore backbone diversity. Side-chain or ligand-contact measures, such as all-atom RMSD over pocket residues, would be needed to test whether side-chain changes alter the conclusions.
